## 使用方式
這是純前端 HTML/CSS/JavaScript 專案，不需要 npm 安裝或編譯。
以靜態伺服器提供 dist 目錄，例如 python -m http.server 8000 --directory dist，瀏覽 http://localhost:8000。
主要檔案：dist/index.html（頁面入口）、dist/style.css（樣式）、dist/app.js（功能）、dist/excel-lib.js（Excel 整理工具與相依程式）、dist/report.html（月報工具）。
使用者資料存於瀏覽器 localStorage，鍵為 aming-calibration-demo-v1。原始碼不含使用者在已發布網站中輸入的資料；轉移資料請使用原網站的「備份與還原」。不要改掉儲存鍵或自動清空資料。
這份匯出不含原網站的部署權限、憑證或 Git 設定。修改本地檔案不會自動更新原 Sites 網址。

## 合作方式
以繁體中文溝通。使用者要一個畫面一個畫面確認，先調整行事曆。保持簡約、淺底、鮮豔而有質感，字體偏大。不要自行全面重設計，也不要新增介紹配色的文字。

## 已確認規則
- 內校藍色 #2e5894，外校及遊校黃色 #ffb300，逾期紅色 #b44747，其他事項灰黑 #222222。
- 所有項目完成後統一淺白灰（現有色值 #fdf5e6）並加刪除線，完成色優先於原類別或逾期色。
- 行事曆月份間用粗線區隔；今天有框線。保留年月切換與回到今天。
- 待辦事項新增按鈕只顯示「＋」；不顯示「今日事項」小標。
- 新增行程按鈕位於行事曆區域右上方；右側待辦區向上延伸。整體字體已再次放大。
- 新增行程與新增待辦分開：行程必填日期；待辦只填項目與備註，不輸入日期。
- 待辦及逾期事項直接點項目文字切換完成，不顯示打勾方框、不確認完成日期；完成文字加刪除線，再點可取消完成。
- 逾期完成後，從原行事曆日期移除，改放到完成當日（當月）；依較新的規則統一使用完成色與刪除線。取消完成恢復原日期。
- 行程明細標題只顯示日期，項目預設收起，點擊展開；不顯示資料來源那排文字。
- 明細只呈現項目標題及小項目；編輯、刪除呈現按鈕。完成／取消完成在待辦區操作，明細不顯示完成日期。
- 明細保留右上角叉叉，移除右下角關閉按鈕。
- 內校行事曆顯示簡短設備編號；外校顯示外校收件_廠商、外校寄出_廠商、遊校_廠商。完整設備編號於明細呈現。
- 原有其他功能：設備管理清冊、設備管理月報、內外校進度、外校金額、匯入、備份與還原。延續現有程式。
